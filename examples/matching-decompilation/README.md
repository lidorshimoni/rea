# Matching Decompilation Example

This directory contains a complete, self-contained example demonstrating REA's **Matching Decompilation Workflow** on an x86-64 ELF binary.

It shows how to:

1. Compile a baseline target binary (`target.bin`) with deterministic compiler flags.
2. Inspect the binary for matching decompilation feasibility.
3. Carve the binary into relocatable assembly stubs and prove **Day 0 100% bit-exact relinking**.
4. Lift routines into idiomatic C99 translation units (`src/crc32.c`, `src/sequence.c`).
5. Use relocation-masked object diffing to verify **100.0% exact machine code equivalence**.
6. Run the offline **Semantic Decompilation Enrichment Suite (SDES)** to recover macros and library signatures.
7. Track verified progress in the **Reconstruction Obligation Ledger**.

## Step-by-Step Walkthrough

### 1. Compile the Baseline Target Binary

Run `build_target.sh` to compile `target.bin` from `target_src/main.c`:

```bash
./examples/matching-decompilation/build_target.sh
```

This compiles `target.bin` using:

```bash
gcc -O2 -fno-pie -no-pie -fomit-frame-pointer -fno-asynchronous-unwind-tables target_src/main.c -o target.bin
```

The script also computes `target.bin`'s SHA256 digest and records it in `decomp.yaml`.

---

### 2. Inspect the Target Binary

Run `inspect-decomp-binary` to evaluate format, architecture, section tables, and feasibility:

```bash
rea inspect-decomp-binary examples/matching-decompilation/target.bin
```

Example output:

```yaml
format: ELF64
architecture: x86_64
bits: 64
endianness: little
image_base: 0x00400350
entry_point: 0x004010c0
feasible_1to1_match: true
```

---

### 3. Linear Partition Splicing & Day 0 Relink Parity

Partition the binary into relocatable assembly stubs and generate the memory-pinned linker script:

```bash
rea split-decomp-slices examples/matching-decompilation
```

Now, verify the **Day 0 Full-Binary Relink Invariant**:

```bash
rea build-decomp-unit examples/matching-decompilation --relink
```

Output:

```yaml
normalized_result:
  success: true
  compiler_output: "Relink successful. Parity match: 100.0% EXACT"
  relink_success: true
  full_binary_match: true
```

This proves that before writing a single line of C, the build system can already produce a 100% byte-exact binary.

---

### 4. Lift and Verify Translation Units

Compile and diff the lifted translation units against their baseline slices:

#### A. Monotonic Sequence Allocator (`advance_sequence`)

Compile the candidate unit:

```bash
rea build-decomp-unit examples/matching-decompilation --symbol advance_sequence --unit src/sequence.c
```

Diff against the target binary slice:

```bash
rea check-decomp-unit examples/matching-decompilation advance_sequence --unit src/sequence.c
```

Output:

```yaml
normalized_result:
  unit: src/sequence.c
  symbol: advance_sequence
  status: matched
  match_percent: 100
  similarity: 1
  total_bytes: 35
  matched_bytes: 35
```

#### B. 32-Bit CRC Checksum (`calculate_crc32`)

Compile the candidate unit:

```bash
rea build-decomp-unit examples/matching-decompilation --symbol calculate_crc32 --unit src/crc32.c
```

Diff against the target binary slice:

```bash
rea check-decomp-unit examples/matching-decompilation calculate_crc32 --unit src/crc32.c
```

Output:

```yaml
normalized_result:
  unit: src/crc32.c
  symbol: calculate_crc32
  status: matched
  match_percent: 100
  similarity: 1
  total_bytes: 97
  matched_bytes: 97
```

Both routines match the original binary **byte-for-byte (100.0%)**!

---

### 5. Semantic Decompilation Enrichment (SDES)

Run the offline semantic enrichment suite to detect third-party library signatures, extract magic constants, and synthesize Doxygen documentation:

```bash
rea enrich-decomp-project examples/matching-decompilation
```

Output:

```yaml
summary: "Enriched project: matching_decomp_example. Detected 3 3rd-party libraries (7 symbols). Recovered 5 magic constants into include/macros.h. Added 4 comments across 1 files."
```

This updates:

- `include/macros.h`: Recovers `CRC32_POLYNOMIAL` (`0xEDB88320`), `PAGE_SIZE_4K` (`0x1000`), etc.
- `include/libraries.h`: Documents detected zlib, libc, and cJSON interfaces.

---

### 6. Synchronize Reconstruction Obligations

Update `ledger.json` to lock in verified 100% matching symbols:

```bash
rea sync-decomp-obligations examples/matching-decompilation
```

The obligation ledger guarantees auditability and tracks overall progress toward complete source code recovery.
